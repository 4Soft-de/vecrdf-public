# VEC - RDF Toolkit - Public Repository

This is the public repository of the 4Soft VEC RDF Toolkit. The Toolkit can be used to convert VEC XML to RDF and to validate semantic rules on this data. It was developed to support the prostep ivip ECAD-IF in its mission to ensure interoperable implementations of the VEC. It can be used to execute the ECAD-IF compliance test suite. A detailed description of this can be found in the [ECAD-WIKI](https://ecad-wiki.prostep.org/specifications/vec/guidelines/compliance-tests/).


It is based on our OSS VEC RDF Api, that is part of the [Harness Model API](https://github.com/4Soft-de/harness-model/tree/develop/vec-rdf) hosted on GitHub. The Execution Engine itself has proprietary [license](/LICENCE) and can be downloaded for free from our homepage: [4Soft Documentation of VEC RDF Toolkit](https://www.4soft.de/downloads/vec-rdf/).
